# Documentation Technique : `CLI Bridge Context Payload`

## 1. En-tête

*   **Titre**: Plan : CLI Bridge Context Payload
*   **Description concise**: Ce plan vise à enrichir le contexte fourni au `GeminiCliSession` pour le `CLI Bridge` en y intégrant un assemblage de contexte structuré et atomique (identité/système, architecture/arborescence, RAG, historique), similaire à l'approche DeepSeek, tout en isolant le processus `gemini-cli` de ses fichiers de configuration `.GEMINI.md` afin d'assurer des réponses cohérentes et fortement contextualisées.
*   **Dépendances du plan**:
    *   `builder-context`: Introduction d'un builder de prompt atomique.
    *   `cli-session-context`: Branchement de `GeminiCliSession` sur ce builder, incluant gestion de troncature/limites.
    *   `cli-isolation`: Isolation du `gemini-cli` des fichiers `.GEMINI.md` via environnement contrôlé.
    *   `logging-bridge`: Ajout de logs de diagnostic pour le CLI Bridge.
    *   `tests-builder`: Tests unitaires du builder de prompt.

## 2. Classes & Fonctions

### Module / Composant: `ai_core/prompt_builders.py` (ou `ai_core/sessions.py` pour une factorisation)

#### Fonction / Classe: `ContextPayloadBuilder`

Ce composant est responsable de l'assemblage structuré des différents éléments de contexte en une chaîne de caractères unique, prête à être soumise à un modèle de langage.

*   **Signature**:
    ```python
    class ContextPayloadBuilder:
        def build_context_payload(
            self,
            system_instruction: str,
            user_message: str,
            rag_context: Optional[str] = None,
            history: Optional[List[Tuple[str, str]]] = None,
            global_cache_components: Optional[Dict[str, str]] = None,
            max_total_tokens: Optional[int] = None,
            truncation_strategy: str = "middle"
        ) -> str:
            # ...
    ```
*   **Arguments**:
    *   `system_instruction` (str): Instructions système ou identité du modèle.
    *   `user_message` (str): Le message actuel de l'utilisateur.
    *   `rag_context` (Optional[str]): Contenu issu de la Recherche Augmentée par Génération (RAG).
    *   `history` (Optional[List[Tuple[str, str]]]): Historique de la conversation, sous forme de liste de (rôle, message).
    *   `global_cache_components` (Optional[Dict[str, str]]): Composants de contexte global (e.g., `'arch': '...', 'tree': '...'`) fournis par `GlobalCacheManager`.
    *   `max_total_tokens` (Optional[int]): Limite de taille totale du payload en tokens.
    *   `truncation_strategy` (str): Stratégie de troncature si `max_total_tokens` est dépassé (e.g., `"middle"`, `"tail"`).
*   **Retours**:
    *   `str`: Le payload de contexte complet et structuré, prêt pour le modèle.
*   **Logique interne**:
    1.  **Ordonnancement**: Assemble les sections dans un ordre prédéfini et stable (Instructions, ARCH, TREE, RAG, Historique, Message Utilisateur).
    2.  **Formatage**: Chaque section est encapsulée avec des marqueurs clairs (e.g., `=== SECTION_NAME ===`).
    3.  **Intégration du cache**: Injecte les composants `'arch'`, `'tree'` (et potentiellement `'ltm'`) de `global_cache_components`.
    4.  **Gestion de l'historique**: Formate l'historique en paires `User: ...\nAssistant: ...`.
    5.  **Troncature**: Si `max_total_tokens` est spécifié, applique une stratégie de troncature aux sections les plus volumineuses (`tree`, `rag_context`, `history`) pour respecter la limite, en priorité aux sections moins critiques. La troncature est loguée à des fins de diagnostic.

### Classe: `ai_core/sessions.py::GeminiCliSession`

Cette classe gère l'interaction avec le CLI Gemini via un processus externe. Les modifications proposées visent à la rendre plus robuste et contextualisée.

#### Méthode modifiée: `_build_full_prompt` (ou équivalent)

*   **Signature**:
    ```python
    class GeminiCliSession(BaseSession):
        # ...
        def _build_full_prompt(self, message: str, rag_context: Optional[str]) -> str:
            # ...
    ```
*   **Arguments**:
    *   `message` (str): Le message de l'utilisateur.
    *   `rag_context` (Optional[str]): Le contexte RAG à inclure.
*   **Retours**:
    *   `str`: Le prompt final à envoyer au processus `gemini-cli`.
*   **Logique interne**:
    1.  **Utilisation du builder**: Appelle `ContextPayloadBuilder.build_context_payload` en lui passant:
        *   L'instruction système par défaut de la session.
        *   Le `message` de l'utilisateur.
        *   Le `rag_context` fourni.
        *   L'historique de conversation interne à `GeminiCliSession`.
        *   Les composants architecturaux (`arch`, `tree`) récupérés via `GlobalCacheManager.get_components()`.
        *   Des limites de `max_total_tokens` pour le CLI.
    2.  **Journalisation**: Enregistre les détails du prompt construit (tailles des sections, troncatures) via le logger `AI_CORE`.

#### Méthode modifiée: `_execute_cli_command` (ou équivalent pour l'invocation du sous-processus)

*   **Signature**:
    ```python
    class GeminiCliSession(BaseSession):
        # ...
        def _execute_cli_command(self, prompt: str) -> str:
            # ...
    ```
*   **Arguments**:
    *   `prompt` (str): Le prompt complet préparé par `_build_full_prompt`.
*   **Retours**:
    *   `str`: La réponse du CLI Gemini.
*   **Logique interne**:
    1.  **Isolation de l'environnement**: Lors de l'appel à `subprocess.Popen` ou `subprocess.run`:
        *   Définit un `cwd` (current working directory) vers un répertoire temporaire vide pour empêcher le CLI de charger des fichiers `.GEMINI.md` locaux.
        *   Modifie les variables d'environnement (`env`) passées au sous-processus pour explicitement désactiver la lecture de fichiers `.GEMINI.md` ou de configurations de contexte externe. (Approche à valider selon la documentation/comportement précis du `gemini-cli`).
        *   Optionnellement, passe un fichier de configuration minimal au CLI si un contrôle fin via les variables d'environnement n'est pas possible.
    2.  **Journalisation**: Enregistre l'état de l'invocation du CLI (chemin, taille du prompt soumis, éventuels avertissements d'environnement).

### Module: `ai_core/logging.py`

#### Ajout: Log `AI_CORE`

*   **Description**: Un nouveau niveau de journalisation ou un logger dédié pour les diagnostics internes au `CLI Bridge`.
*   **Logique interne**:
    *   Capture les tailles des sections du prompt (arch, tree, rag, history).
    *   Indique si des troncatures ont eu lieu et quelles sections ont été affectées.
    *   Enregistre le chemin du binaire CLI et le modèle utilisé.
    *   Assure qu'aucune information sensible n'est exposée dans les logs.

### Module: `tests/test_cli_bridge_prompt.py`

#### Fonctions de test: `test_prompt_builder_structure`, `test_prompt_builder_truncation`

*   **Signature**:
    ```python
    def test_prompt_builder_structure():
        # ...
    def test_prompt_builder_truncation():
        # ...
    ```
*   **Arguments**: Aucun.
*   **Retours**: Aucun.
*   **Logique interne**:
    1.  **`test_prompt_builder_structure`**:
        *   Instancie `ContextPayloadBuilder`.
        *   Appelle `build_context_payload` avec diverses entrées (system, message, rag, history, cache components).
        *   Vérifie que la chaîne de sortie contient toutes les sections attendues et qu'elles sont dans le bon ordre.
        *   Vérifie le formatage des sections (ex: `=== RAG ===`).
    2.  **`test_prompt_builder_truncation`**:
        *   Prépare des entrées volumineuses pour `rag_context`, `history` et `global_cache_components` (`tree`).
        *   Appelle `build_context_payload` avec une `max_total_tokens` restrictive.
        *   Vérifie que les sections volumineuses ont été correctement tronquées.
        *   S'assure que les sections critiques (comme `system_instruction` ou `user_message` initial) ne sont pas affectées ou le sont en dernier recours.

## 3. Exemple d'usage

```python
# Fichier: ai_core/sessions.py

from ai_core.prompt_builders import ContextPayloadBuilder
from ai_core.cache_manager import GlobalCacheManager
from ai_core.logging import AI_CORE_LOGGER # Supposons un logger configuré

class GeminiCliSession:
    def __init__(self, cli_path: str, model_name: str):
        self.cli_path = cli_path
        self.model_name = model_name
        self.history = [] # Format: [("User", "msg"), ("Assistant", "resp")]
        self.prompt_builder = ContextPayloadBuilder()
        self.system_instruction = "Tu es un assistant utile..."

    def _build_full_prompt(self, message: str, rag_context: Optional[str] = None) -> str:
        # Récupérer les composants du cache global (arch, tree, etc.)
        global_components = GlobalCacheManager.get_components()

        # Construire le payload de contexte
        full_prompt = self.prompt_builder.build_context_payload(
            system_instruction=self.system_instruction,
            user_message=message,
            rag_context=rag_context,
            history=self.history,
            global_cache_components=global_components,
            max_total_tokens=4000 # Exemple de limite de tokens
        )

        # Log de diagnostic
        AI_CORE_LOGGER.info(f"Prompt CLI Bridge construit: "
                            f"Model={self.model_name}, "
                            f"Longueur={len(full_prompt)} chars, "
                            f"Sections: ARCH={len(global_components.get('arch', ''))} "
                            f"TREE={len(global_components.get('tree', ''))} "
                            f"RAG={len(rag_context or '')} "
                            f"HISTORY={sum(len(m[1]) for m in self.history)}")

        return full_prompt

    def _execute_cli_command(self, prompt: str) -> str:
        import subprocess
        import tempfile
        import os

        # Créer un répertoire temporaire pour l'isolation
        with tempfile.TemporaryDirectory() as temp_dir:
            # Préparer les variables d'environnement pour désactiver GEMINI.md
            # Note: Les noms exacts de variables peuvent varier selon le CLI
            env = os.environ.copy()
            env["GEMINI_CONFIG_DISABLE_CONTEXT_FILES"] = "true" # Exemple
            env["GEMINI_CWD_OVERRIDE"] = temp_dir # Optionnel, si le CLI le respecte

            try:
                result = subprocess.run(
                    [self.cli_path, "prompt", prompt],
                    capture_output=True,
                    text=True,
                    check=True,
                    cwd=temp_dir, # Exécute le CLI depuis le répertoire temporaire
                    env=env
                )
                AI_CORE_LOGGER.debug(f"CLI Bridge Output: {result.stdout.strip()}")
                return result.stdout.strip()
            except subprocess.CalledProcessError as e:
                AI_CORE_LOGGER.error(f"CLI Bridge Error (code {e.returncode}): {e.stderr}")
                raise

    def send_message(self, message: str, rag_context: Optional[str] = None) -> str:
        full_prompt = self._build_full_prompt(message, rag_context)
        response = self._execute_cli_command(full_prompt)
        self.history.append(("User", message))
        self.history.append(("Assistant", response))
        return response

# Exemple d'utilisation
if __name__ == "__main__":
    # Supposons que 'gemini-cli' est dans votre PATH ou spécifiez le chemin complet
    cli_session = GeminiCliSession(cli_path="gemini", model_name="gemini-pro")

    # Simuler des composants de cache
    GlobalCacheManager.set_components({
        "arch": "Architecture du projet: MonProjet utilise Python, Flask, et une base de données PostgreSQL.",
        "tree": "Arborescence simplifiée:\n- src/\n  - models.py\n  - views.py\n- tests/\n- docs/"
    })

    # Premier message
    response1 = cli_session.send_message(
        "Comment puis-je ajouter une nouvelle route à mon application Flask ?",
        rag_context="Fichier: src/views.py - Contient des exemples de routes existantes."
    )
    print(f"Assistant: {response1}")

    # Deuxième message, utilisant l'historique et le contexte
    response2 = cli_session.send_message(
        "Peux-tu me donner un exemple de route pour '/api/items' en utilisant Flask-RESTful ?",
        rag_context="Doc: Flask-RESTful - Ressource exemple ItemResource."
    )
    print(f"Assistant: {response2}")
```
