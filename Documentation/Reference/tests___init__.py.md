# tests/__init__.py

Ce fichier initialise le package de tests. Il est généralement utilisé pour définir des variables globales ou exécuter des configurations communes à tous les tests. Dans ce cas précis, le fichier est vide, ce qui signifie qu'il est utilisé uniquement pour indiquer que le répertoire `tests` doit être traité comme un package Python.

## Dépendances

Aucune dépendance spécifique à ce fichier.

## Classes & Fonctions

Ce fichier ne contient aucune classe ni fonction définie. Son rôle est purement structurel pour la gestion des packages Python.

## Exemple d'usage

Étant donné que ce fichier est vide, il n'y a pas d'exemple d'usage direct pour le fichier lui-même. Son utilité réside dans le fait qu'il permet à Python de reconnaître le répertoire `tests` comme un package, ce qui est essentiel pour l'exécution des tests unitaires ou d'intégration par des outils comme `pytest` ou `unittest`.

Lorsque vous exécutez des tests, par exemple avec la commande `pytest`, la présence de ce fichier (même vide) permet à `pytest` de découvrir les modules de test contenus dans ce répertoire.
